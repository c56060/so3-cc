## 🛠️ 工具简介

落雪音乐（LX Music，亦称洛雪音乐助手）是一款由开发者 lyswhut 发起、基于 Electron 与 Vue 构建的开源音乐软件，项目代码托管于 GitHub 并采用 Apache-2.0 协议公开，从根源上杜绝了商业化套路。它本身不存储任何音乐文件，而是通过聚合主流音乐平台的公开接口，将分散在各处的歌曲资源整合到一个统一的搜索与播放界面中，覆盖 Windows、macOS、Linux 与 Android 四大平台，开发者明确暂不支持 iOS 与鸿蒙，坚持在开放生态里打磨产品。

在会员付费、广告弹窗、平台壁垒层层包裹的数字音乐环境下，听歌这件本应简单的事变得愈发繁琐——同一首歌可能分散在三四个平台，想听完喜欢的歌单得来回切换软件、重复收藏，会员更是开了一个又一个。落雪音乐正是为应对这种割裂体验而生：它把搜索、试听、下载、歌单管理、桌面歌词等能力集中在一个清爽的界面里，没有开屏广告、没有弹窗推送、没有会员诱导，只做一件事——让用户安心听歌。

这款工具适合受够了平台会员制与广告打扰的听歌爱好者，需要在一个软件内搜索全网曲目的重度用户，追求纯净桌面歌词体验的办公学习党，以及使用 Linux 或 macOS 想找一款跨平台音乐软件的用户。需要注意的是，由于受到版权方警告，官方已不再内置音源，用户需自行导入自定义音源才能正常搜索播放。

### ✨ 核心功能

*   **多平台音源聚合搜索**：内置多个音乐平台接口（如小蜗音乐、小枸音乐、小秋音乐、小芸音乐、小蜜音乐等），支持"聚合大会"模式将各平台歌曲汇集到一起，输入歌名、歌手或专辑即可一键检索全网资源。
*   **自定义音源导入**：支持在线导入与本地导入两种方式，用户可将音源脚本添加到"自定义源管理"，按需拓展资源库，兼顾通用性与灵活性；某个音源失效时可自动切换到其他可用源，保证听歌不中断。
*   **桌面歌词与可视化**：桌面歌词可置顶、可半透明，支持调整透明度避免遮挡工作内容；逐字高亮歌词滚动流畅，支持翻译与罗马音显示；还提供音频可视化效果，可一键关闭。
*   **无损音质播放与下载**：支持普通、高品质、无损 APE、无损 FLAC 等多种音质，可在线试听也可下载到本地，边听边下，下载路径与文件命名方式可自定义。
*   **跨平台多端与歌单管理**：覆盖 Windows、macOS、Linux、Android 四大平台；支持自建歌单、收藏列表、播放历史自动记忆；可导入主流平台歌单链接或 ID 无缝迁移曲库；数据存储在本地不依赖云端，隐私更安全。

## 💡 适用场景

**多平台听歌切换疲惫的用户**：当你同时在网易云、QQ音乐、酷狗、咪咕等多个平台都有想听的歌，与其挨个开软件、挨个充会员，不如在落雪音乐里用"聚合大会"一次搜全，省去频繁切换的麻烦。

**追求纯净无打扰听歌体验的用户**：开屏广告、弹窗推送、会员诱导、直播入口堆砌——这些商业播放器的"标配"在落雪音乐里全部不存在，打开软件映入眼帘的就是歌曲本身，没有学习成本，上手即用，适合把听歌当享受而非消费的人。

**需要桌面歌词的办公学习党**：桌面歌词支持自定义透明度，可在写文档、敲代码、看网课时半透明悬浮于屏幕之上，看词与做事两不误，比传统遮挡式桌面歌词更友好。

**Linux/macOS 用户寻找跨平台软件**：市面主流音乐软件对 Linux 支持有限，落雪音乐同时提供 Windows、macOS、Linux 桌面版与 Android 移动版，包名统一为 cn.toside.music.mobile，数据存储路径各平台对应清晰，方便多设备协同。

**希望无缝迁移歌单的用户**：支持通过歌单链接或歌单 ID 导入主流平台歌单，无需逐首手动添加，可快速把原有曲库搬到本地管理，搭配本地下载与离线播放，构建私人曲库。
